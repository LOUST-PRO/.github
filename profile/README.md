## 🤖 Development Pipeline & Agentic Workflow

LOUST-PRO operates heavily on an **AI-Native Engineering Pipeline**, utilizing autonomous agents (Antigravity IDE, Claude, Gemini) embedded deeply into the development lifecycle via the **Model Context Protocol (MCP)**.

If you are contributing or running agents in our repositories, adhere to the following workflow:

1. **Broker Integration:** Ensure your agent is connected to the LZT Harness. We use dual-binary GitHub automation (`TaxonRouter` and `lzt-github-projects-mcp-go`) to manage PRs, project boards (ProjectV2), and SEO meta-tags dynamically.
2. **Deterministic Context:** All data pipelines and context retrieval must align with the *Deterministic Sovereign RAG* spec. Use `LLMmempipe` to trim noise before injecting context into the agent's window.
3. **Stage-Local First:** All modifications, agent planning, and vulnerability scans must run locally in a sandboxed stage before proposing upstream PRs.
